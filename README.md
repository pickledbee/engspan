English ♥ Español

A totally private two-person translated chat room. Messages are stored in your own Google Sheet through a Google Apps Script web app. There are no API keys in this repository.

Live site: https://pickledbee.github.io/engspan/

Files
index.html            The website. Set API_URL near the bottom to your Apps Script /exec link.
apps-script/Code.gs   Paste into the Google Sheet's Extensions > Apps Script. Run setup, set the password, deploy as a web app.
bg.jpg                Background photo.
