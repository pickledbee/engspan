English ♥ Español

Private translated chat rooms. Sign in with Google or email and password, create a room, send the invite link to the person you choose, and lock the room so nobody else can join. Each person reads every message in their own language.

Live site: https://pickledbee.github.io/engspan/

Files
index.html          The app.
firebase-config.js  Firebase web settings (public by design).
firestore.rules     Database security rules (already published in Firebase).
